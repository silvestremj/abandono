# Predictor de Abandono Escolar

Pipeline de datos y modelo de evaluación de riesgo para el Trabajo de Fin de Máster (TFM).

## Requisitos previos
* Python 3.10 o superior.

## Instalación
Para instalar todas las librerías y dependencias necesarias, abre la terminal y ejecuta:

```bash
pip install -r requirements.txt
```

## Ejecución
python.py
